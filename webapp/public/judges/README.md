# 면접관 영상

여기에 면접관마다 반복 영상 2개를 넣으면 앱이 그림 대신 영상을 씁니다. 없으면 그림으로 나옵니다.

| 파일 | 내용 |
|---|---|
| j1-idle.mp4, j1-talk.mp4 | 면접관 1 (화면 왼쪽) |
| j2-idle.mp4, j2-talk.mp4 | 면접관 2 (가운데) |
| j3-idle.mp4, j3-talk.mp4 | 면접관 3 (오른쪽) |

- idle: 가만히 듣는 모습 (눈 깜빡임, 살짝 끄덕임), talk: 말하는 모습. 각각 5~10초, 처음과 끝이 이어지게
- 세로 5:6 비율 (예: 500×600), 가슴 위, 정면, 소리 없음, 파일 하나에 2MB 이하 (H.264 mp4)
- 실제 사람 사진·영상은 본인 동의 없이 쓰지 말 것. AI로 만든 가상 인물만
